# Party like a Princess Demo Website

A modern demo website for [Party like a Princess LLC](https://www.partylikeaprincessllc.com/) — magical character entertainment and children's parties in Rolesville & the Triangle, NC.

## Pages

- **Home** (`index.html`) — Hero, values, package previews, events, and character highlights
- **Party Packages** (`packages.html`) — Travel parties, studio packages, karaoke, and spa parties
- **Characters** (`characters.html`) — Filterable gallery of princesses, superheroes, villains, and more
- **Book a Party** (`book.html`) — Contact form and booking information
- **About Us** (`about.html`) — Krystal's story and studio details
- **Businesses We Love** (`partners.html`) — Local community partners

## Features

- Responsive design with a sweet princess aesthetic — blush pink, lavender, and gold accents
- Playfair Display + Dancing Script + Quicksand typography
- Character gallery with category filters
- All package pricing and details from the live site, presented as clean cards instead of image flyers
- Content sourced from the business's current website and public listings

## Local Preview

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **GitHub Actions** (workflow included)
4. Your site will be live at `https://mnkuroda.github.io/partylikeaprincesswebsitedemo/`
